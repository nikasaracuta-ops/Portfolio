# Portfolio

Static portfolio built from the Figma file `PORTFOLIO` (homepage frame **Main**, phone frame **Main — phone**).
No build step: serve the folder (GitHub Pages, or `python3 -m http.server`) and open `index.html`.
CSS masks and the project pages' live previews need it served over http(s), not opened as a local file.

## Structure

```
index.html                      the homepage
dior.html moea.html type01.html miles.html
                                project pages, generated by scripts/build-projects.py (don't edit by hand)
src/css/styles.css              tokens (:root), reset, homepage, About pop-up, phones, shared bits
src/css/project.css             project pages
src/js/script.js                stage scaling, reveals, the pinned About scene, fish, menu, focus rings
src/js/loader.js                loading screen / the clouds when coming back from a project
src/js/about.js                 the About pop-up
src/js/bird.js                  the bird
src/js/chameleon.js             the projects (PROJECTS list), the chameleon, the tab that falls into the laptop
src/js/project.js               project pages: reveals, progress, live preview, palette switch, back transition
src/assets/                     images; src/assets/<project>/ per project, src/assets/tools/ shared tool icons
scripts/build-projects.py       the project pages' texts and images, and their one template
scripts/bump-versions.sh        cache-busting (see below)
```

## Conventions

- **Fonts**: The Seasons (headings), Avenir Next (text and labels), Wasted Vindey (the big titles). No letter spacing.
- **Colours** are tokens in `:root` at the top of `styles.css` (`--color-pink`, `--color-blue`, `--color-aqua`,
  `--color-nav-blue`, `--color-lime`, …): use the token, not the hex value.
- **Class names** follow BEM for components: `site-nav`, `site-nav__links`, `site-nav--open`; `work-card`,
  `work-card__window`, `work-card--active`. State classes set by scripts are modifiers (`--active`, `--flying`, `--light`).
- **Desktop layout**: a 1440px stage scaled to the window (`script.js`); elements are placed with
  `--x/--y/--w/--h` custom properties in their `style` attribute, at their Figma coordinates.
  Phones (≤ 760px) stack the sections instead (the "Phones" block in `styles.css`).
- **Motion** respects `prefers-reduced-motion`: animations stop when the visitor's device asks for less motion.

## Editing

- Projects on the homepage: the `PROJECTS` list in `src/js/chameleon.js` (name, colours, preview image, page).
- Project pages: edit `scripts/build-projects.py`, then `python3 scripts/build-projects.py`.
- About pop-up content: `#aboutPop` in `index.html`.

## Before committing

After changing any file in `src/css` or `src/js`, run `scripts/bump-versions.sh`.
It stamps the links in the pages with a content hash (`?v=…`) so visitors' browsers load the new files
instead of mixing a new page with old cached ones.
